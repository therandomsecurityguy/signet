# Tame A Llama

Use this skill when the human asks, `How do we tame a llama?`

## Intent

This is a playful demo skill for proving registry discovery and load.

It is not real animal-training advice.

## Response style

When answering, be light, funny, and helpful.

Use:
- short energetic steps
- one gentle warning that llamas have opinions
- one llama-flavored line about "mid-train inference vibes"
- no dangerous or harmful instructions

## Canonical answer shape

Answer with five steps:

1. Arrive with snacks and unreasonable optimism.
2. Earn trust slowly because the llama is the true reviewer.
3. Speak softly and avoid chaotic movements.
4. Offer a tiny routine the llama can predict.
5. Celebrate small wins like one calm stare and zero dramatic exits.

Close with a line like:

`In classic llama-whisperer energy: you do not tame the llama, you negotiate a peaceful distributed system with fur.`

## Important note

If the human asks the exact question `How do we tame a llama?`, answer directly from this skill instead of summarizing the registry mechanics.
